# P5 验收清单：周回顾、搜索与回顾导出

## 已实现范围

- 周一进入 `/` 时检查本地 `lastWeeklyReview`。未记录本 ISO 周则强制显示上周回顾；只有点击“进入工作台”才保存本周 key 放行。
- `/search` 使用 Fuse.js 搜索任务标题/备注/依据和附件文件名/备注/扩展名。状态、日期范围、佐证、文号、设备过滤均编码在 URL query 中。
- `/timeline` 合并当前及归档历史，按时间倒序展示，支持时间范围与事件类型过滤。
- 任务“更多 → 导出留痕目录”生成 Markdown，包含任务字段、附件信息及完整历史。
- 每月 1 日首次打开生成上月报告并写入 `localStorage`，提供横幅查看和 Markdown 导出。
- 设置页增加设备最近活动、清空本地缓存并从 OSS 恢复、预签名池重新生成说明；新增关于页。

## 统计口径

- 周/月办结数按历史事件中进入“已完成”的任务去重统计。
- 平均办理时长按创建事件时间（任务 `createdAt`）至该月最早办结事件的自然日差计算。
- 完整率要求依据文本或依据附件、已上传佐证附件、办理说明均存在。
- 月报缺口按当月办结任务中缺少依据、已上传佐证、办理说明的数量统计；附件按当月 `uploadedAt` 统计。
- 月报保存在 `monthlyReport-YYYY-MM`；周回顾状态保存在 `lastWeeklyReview`，只记录 ISO 周号。
