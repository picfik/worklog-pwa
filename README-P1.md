## 构建

- [x] 执行 `npm run build`，构建成功且无 TypeScript 错误。

## 任务与状态

- [x] 手机尺寸下快速新建任务，编辑状态、依据、截止日期和备注，刷新后数据仍在。
- [x] `todo → doing` 无依据时允许流转并标记 incomplete；完成状态变化会记录设备和历史事件。
- [x] 笔记本双栏可编辑任务，改变窗口宽度会自动在双栏与窄屏布局间切换。
- [x] 备注可在 Markdown 编辑与安全预览之间切换，字段修改约 500ms 后自动保存。
- [x] 手机任务详情默认只读；点击“编辑”后可补状态、依据和备注。
- [x] 归档已完成任务后，任务从 `tasks` 移除并进入对应 `archives/YYYY-MM` 分片，历史事件随任务进入归档分片。
- [x] 任务时间线按事件时间倒序显示，状态描述为中文。

## 快速捕获与快捷键

- [x] 手机快速捕获抽屉标题必填，保存后关闭并提示“已记，待同步”。
- [x] 手机拍照选择只将照片 Blob 与文件名登记到 pendingUploads，不上传附件。
- [x] 当前浏览器支持语音输入并显示语音按钮。
- [x] Ctrl/Cmd+Shift+N 连续创建 3 条，三条任务的 captureSessionId 相同。
- [x] Ctrl/Cmd+N 新建；Ctrl/Cmd+K 聚焦搜索；Ctrl/Cmd+S 显示同步占位提示；Ctrl/Cmd+Enter 推进状态；Ctrl/Cmd+B 折叠任务栏；Esc 关闭捕获层。
